# Agent Directives: jeffstandre-web

## Architecture & Stack
- Pure static web: Semantic HTML5, CSS3, Vanilla ES6 JavaScript.
- Zero build steps or package managers (no Node, npm, Vite, or Webpack).
- Markdown rendering: Render `/posts/*.md` client-side using `marked.min.js` and `prism.js` from CDN.
- Domain target: jeffstandre.com hosted on GitHub Pages.

## Aesthetic Guidelines
- Clean, welcoming, and thoughtful personal website.
- Rich, comfortable dark palette: Deep space black (`#0a0c10`, `#121620`), stark white headings (`#ffffff`), and Jeff's signature **`#a9a42c`** olive-chartreuse for warm, tasteful accents and avatar framing.
- Human, conversational, and accessible tone: avoid synthetic AI tropes, pseudo-military jargon, or artificial telemetry clichés.
- High-legibility typography (`Inter` + `JetBrains Mono` for code/dates), smooth transitions, and comfortable reading measure.

## Site Structure & External Routing

- Projects & Tools: `#projects`.
- Talks & Slides: `#slides` / `/slides/index.html`.
